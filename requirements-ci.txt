# Минимальный набор зависимостей для прогона автотестов в CI.

# Тесты работают с реальными классами проекта (ProductionCycle, правила,
# загрузчики), поэтому numpy/opencv/pyserial нужны по-настоящему. А вот
# ultralytics (тянет torch, сотни мегабайт) и pywebview (требует GTK/Qt в

#
# Ограничения версий совпадают с requirements.txt, чтобы CI проверял ту же
# конфигурацию, что работает на линии. Исключение — opencv: в headless-раннере
# ставится opencv-python-headless (та же библиотека без GUI-модулей и без
# зависимости от libGL).
#
# Для локальной разработки используйте requirements-dev.txt — там полный набор.
