# Физическая логика распределителя

Этот документ — источник истины для логики маршрутизации корпуса. При изменении
`hardware/distributor.py`, `core/production_cycle.py`, UI или тестов эта
механика не должна переопределяться комментариями или визуальными метафорами.

## Оси

### DIST1 — первая заслонка

DIST1 не удерживает корпус, не является лепестком и не открывается «для
сброса» в старом смысле.

| Координата DIST1 | Путь корпуса |
| --- | --- |
| `0` | корпус падает в **GOOD** |
| `340` | корпус направляется на вторую заслонку **DIST2** |

### DIST2 — вторая заслонка

DIST2 влияет на корпус **только** когда DIST1 уже направляет его на DIST2
(`DIST1=340`).

| Координата DIST2 | Путь корпуса |
| --- | --- |
| `0` | **BAD** |
| `340` | **CLEANUP** |

## Маршруты

| Категория | DIST1 | DIST2 |
| --- | ---: | ---: |
| `GOOD` | `0` | не влияет |
| `BAD` | `340` | `0` |
| `CLEANUP` | `340` | `340` |

`dist1_open_position` в старом `calibration.json` — совместимое имя
параметра. Физически это положение DIST1 **«на DIST2»**, а не «открытая
заслонка сброса».

## Очередность для корпуса на +7

1. Корпус на позиции `+7` ожидает следующий шаг ленты. Механического
   удержания заслонкой нет.
2. До команды движения полностью выставляется его маршрут:
   - GOOD: DIST1 → 0;
   - BAD: DIST2 → 0, затем DIST1 → 340;
   - CLEANUP: DIST2 → 340, затем DIST1 → 340.
3. Затем подаётся команда шага конвейера.
4. После подтверждённой остановки (`I1` и строгая проверка `I2`) система
   подтверждает передачу, обновляет счётчики и архивирует корпус.
5. Заслонки не возвращаются автоматически после каждого корпуса. Они
   остаются в текущем положении, пока маршрут следующего корпуса не требует
   изменения.

## Безопасная смена DIST2

Нельзя перемещать DIST2, когда DIST1 находится в `340`, то есть направляет
путь корпуса на DIST2. Для изменения канала порядок всегда такой:

```text
DIST1 → 0
DIST2 → нужное положение
DIST1 → 340       # только если следующий маршрут BAD/CLEANUP
```

Это правило должно быть сохранено независимо от оптимизаций серии одинаковых
корпусов или наличия пустых ячеек на ленте.
